# Aula de Git e GitHub

Material de apoio da disciplina **Programação para Web** do **Colégio Politécnico da Universidade Federal de Santa Maria**, para a turma do **2º semestre do Técnico em Informática para Internet**.

**Professora:** Rossana Freitas Moreira  
**Carga horária:** 4 horas  
**Semestre/Ano:** 02/2026

## Objetivo da aula

Criar uma página HTML simples, registrar duas versões com Git e publicar o projeto em um repositório próprio no GitHub.

## Materiais

- `index.html`: página inicial para a atividade prática.

## Roteiro resumido

1. Baixe o `index.html` e coloque-o em uma nova pasta chamada `aula-git`.
2. Abra o terminal nessa pasta e use `git init` para iniciar o repositório.
3. Confira os arquivos com `git status` e registre a primeira versão com `git add` e `git commit`.
4. Altere o título e acrescente um parágrafo ao `index.html`. Registre a segunda versão.
5. Use `git log --oneline` para conferir os dois commits.
6. Crie um repositório **vazio** chamado `aula-git` na sua conta do GitHub e publique nele seu projeto.
7. Mostre o link do seu repositório e explique a diferença entre Git e GitHub.

Siga o documento do roteiro para ver os comandos e as orientações de cada etapa.
